# FV_datasets Folder Description
This folder contains Focus Volume (FV) datasets corresponding to the **simulation experiment section** of the paper *A robust shape-from-focus framework with immunity to ambient vibration noise for microscopic scenes*:
1. FV dataset of simulation image sequences (no vibration, simulating real scenes)  (Ini_FV-true.mat)
2. FV dataset of simulation image sequences (with vibration) (Ini_FV-before.mat)
3. FV dataset of simulation image sequences (with vibration, processed by the proposed method) (Ini_FV-after.mat)
